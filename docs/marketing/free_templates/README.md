# 로드로그 무료 운행일지 서식 팩

## 파일
- `로드로그_무료_운행일지_서식팩.xlsx` — 엑셀 3종 + 이용안내

### 시트
1. **이용안내·로드로그** — 배포 톤, 소프트 CTA, 면책
2. **01_개인업무_일일운행일지** — 개인차 업무용
3. **02_법인차_공용일지** — 팀/총무 공용
4. **03_월간운행요약** — 월말 한 장 요약

## 배포 채널 (권장 순서)
1. 네이버 블로그 (본문 + 파일 첨부/드라이브 링크)
2. 네이버 카페·지식인 답변 보조 자료
3. 구글 드라이브 / 노션 공개 링크
4. 로드로그 사이트 `/resources` 랜딩(추후)
