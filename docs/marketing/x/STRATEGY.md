## 원칙

1. **노출 극대화**  
   - 훅 1줄이 전부다. 첫 140자에 고통/호기심.  
   - 스레드 3~5단 or 이미지 1장 + 짧은 캡션.  
   - 해시태그 0~2개 (도배 금지). 이모지 0~2.

2. **AI 티 제거** (`HUMAN_VOICE.md`)  
   - 완벽한 대칭 문장·“~에 대해 알아보겠습니다” 금지.  
   - 현장 말투, 구체 숫자/장면 1개, 살짝 불완전해도 OK.

3. **이미지 우선**  
   - 텍스트 장문보다 **1080×1080 또는 1200×675** 카드 1장.  
   - 본문은 캡션 2~5줄 + 링크 1개.

4. **타깃 적중** (`AUDIENCE.md`)  
   - 그날 페르소나 1명만 조준. “모두”에게 말하지 않음.

5. **가드레일**  
   - 로드로그: 절세 보장·세금 폭탄 단정 금지.  
   - WA: 수익/성사 보장·결제 유도 금지.  
   - 동일 문구 복붙 도배·허위 후기 금지.  
   - 자동 게시는 **하루 제품당 1포스트** (쿼터·스팸 리스크 관리).

6. **Grok/X 특혜 환상 금지**  
   - 노출은 참여·시의성·훅으로 만든다. 모델 브랜드 부스트 가정 안 함.

## 게시 루틴 (자동)

1. 매일 스케줄 → `python scripts/x_auto_daily.py`  
2. 캡션 추출 + 이미지 업로드 + `POST /2/tweets`  
3. `META.json`에 tweet id 기록  
4. 키 없음 → 알림만 (`AUTO_POST_SETUP.md`)  
5. 수동 개입: 캡션 수정 후 같은 스크립트 재실행 / `--roadlog-only`
