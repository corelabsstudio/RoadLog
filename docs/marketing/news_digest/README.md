# 로드로그 뉴스 브리핑 (3단계 포맷)

## 선별 기준 (지갑 직결만)
- 포함: 세금, 비용 인정, 세무조사, 운행기록부 의무, 번호판 규제, 벌금·과태료, 보험 요건
- 제외: 신차 출시, 연비 자랑, 단순 교통사고, 서비스와 무관한 자동차 뉴스

## 글 구조 (모든 항목 동일)
1. **핵심 요약** 3~4줄 (전문 전재 금지)
2. **원문 링크** (출처명 + URL)
3. **로드로그 코멘트·해결책** (스탬프·제출용 정리, 세무 보장 문구 금지)

## 등록 방법
1. `items.json`에 항목 추가 (slug 중복 금지)
2. `python scripts/make_news_digest.py`
3. 커밋·배포

## 매일 운영
- 관련 이슈가 있는 날: **해당 건 전부** items.json에 넣고 빌드
- 없는 날: 스킵 (억지 양산 금지 — 품질·SEO)
- slug 권장: `YYYY-MM-DD-짧은영문`

## 라이브
- 목록: https://roadlog.co.kr/blog/news/
- 개별: https://roadlog.co.kr/blog/news/<slug>
