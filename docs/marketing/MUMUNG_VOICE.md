현재 API에서 제공하는 @mumung_fact 원글 40개(1페이지)와 본인 답글 609개(7페이지)를 끝까지 수집해 검토했다. 삭제된 글·API에서 제공하지 않는 글은 포함하지 않는다. 본문 없는 글, 붙여 넣은 AI 관상 풀이·기획서·프롬프트와 첫 자동 글은 말투 표본에서 제외했다. 원문 전체는 운영 배포나 외부 모델 입력에 넣지 않는다.

`modules/social_voice.json`에는 공개 원문 주소와 추출한 문체 규칙만 저장한다. `social_voice.py`는 짧은 반말, 생각 단위 줄바꿈, 문장 길이 변화, 필요한 경우의 ㅋㅋ/ㅎㅎ/ㅠㅠ, 강제 질문·교훈 생략을 홍보 caption과 카드 title/body에 공통 적용한다. 반말 어미만 바꾼 보고서·광고 상투어는 검증에서 거절한다. 모델 미세조정이 아니라 생성 지시와 검증 규칙을 바꾼 것이다.

개인 개발 기록 7개는 실제 작업 사실을 유지해 같은 말투로 다시 썼다. 사용한 소재 ID는 유지해 이미 발행했거나 삭제한 글을 다시 올리지 않는다. 신규 등록 소재도 같은 문체 검증을 거친다. 개인 일지에는 외부 모델 호출이 없다.
