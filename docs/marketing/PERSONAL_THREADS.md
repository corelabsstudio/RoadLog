# Threads @mumung_fact 개인 개발 기록

2026-10-07 온해님 지시: 개인 계정에 실제 프로그램·사이트 개발 고충과 해결 방법을 공개 반응이 좋았던 글의 포맷으로 자동 발행. 한국 시간 매일 09:00·12:00·18:00·21:00, 하루 4회.

- `modules/developer_threads.py`: 기존 서버 안에서 별도 예약/작업 장부/작업자로 실행. 기존 홍보 설정이 꺼져도 개인 예약은 독립 동작.
- `PROMO_THREADS_MUMUNG_FACT_TOKEN`: 전용 계정 토큰. 요청 전/게시 후 `mumung_fact` 확인. `roadlog_saju` 토큰 공유 금지.
- `modules/developer_threads.json`: 확인한 개발 기록 7개와 공개 반응을 확인한 개발 분야 포맷 3개. 근거·확인일·원문 주소·반응을 보관. 원문 문장·신상·사연은 사용하지 않음.
- 새 글은 고충·수정·확인 결과·배운 점을 자체 문구로 조합. 외부 AI에 운영 기록을 보내지 않으며 추가 생성 비용 없음. 상품명·URL·구매 유도 없음. 해결된 범위와 아직 모르는 성과를 구별.
- 한 소재는 한 번만 사용. 같은 시간대의 예약은 중복 실행하지 않음. 최종 발행 전 `UNCERTAIN` 저장, 응답 불확실 시 재게시 금지·예약 중단.
- 확인한 소재 소진 시 자동 예약 중단 및 관리자 알림. 기록을 지어내거나 재탕하지 않음. 관리자의 '새 실제 개발 기록 추가'에서 공개 가능한 문제/해결/결과/배운 점과 확인 근거를 추가한 후 예약 재활성화.
- 새 사이트/프로그램 작업을 마치고 온해님이 이 계정의 개발 일지 운영을 요청한 범위 안에서는, 비밀값·고객 자료·재정 정보 등을 제외한 실제 개발 고충과 해결을 새 소재로 추가할 수 있다. 프로젝트 문서 전체를 자동 수집하거나 공개하지 않는다.
- 메뉴: 운영 현황 → 홍보·발행 → 개인 개발 기록 · Threads @mumung_fact. 개인 예약·연결 확인·미리보기·게시 내역·소재 추가 관리.
- 운영 검증 도구: `scripts/configure_personal_threads.py`. --provision은 기존 전용 토큰 등록, --preview는 미리보기, --publish-first는 확인한 첫 글 발행, --enable은 게시 검증 후 요청된 하루 4회 예약 활성화. 비밀값 출력 금지.

검증: `scripts/test_developer_threads.py`(개인 계정/중복/불확실성/소재 소진/인증), `scripts/test_promotion.py`(기존 기능), `roadlog-saju/tools/ship.py --check`.
