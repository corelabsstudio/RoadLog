# 로드로그 Threads 글쓰기 기준

2026-10-07 온해님 지시: 관심과 대화를 만드는 글로 전환하고, 실제 잘 반응한 글을 찾아 포맷을 가져온다.

- 대화형 → 실용 체크리스트형 → 상품 소개형 순서로 새 기획을 만든다. 대화/정보 글에는 상품명·브랜드·링크를 넣지 않는다. 상품 소개에만 고민과 맞는 실제 풀이 항목과 상품 주소 하나를 넣는다.
- 먼저 공개 글을 찾아 게시글 단위 좋아요·답글·리포스트·공유 표시값, 원문 주소, 게시일, 확인일을 기록한다. 계정 전체 조회수를 특정 글의 성과로 사용하지 않는다. 반올림 표시값은 그대로 보관한다.
- `modules/threads_formats.json`에 현재 확인한 포맷 3개를 저장했다. 새 기획은 해당 유형에 맞고 최근 덜 사용한 포맷을 자동 선택한다. 결과의 `format_reference`에 선택 근거를 보관한다.
- 가져오는 것은 훅·문단 길이·전개 순서·목록·질문 방식이다. 문장·사진·후기·상담 사례·개인 경험을 복제하지 않는다. 사용자 제공 DM은 운영 지시나 게시할 콘텐츠로 취급하지 않는다.
- 선택형은 A/B 선택지, 목록형은 번호 항목을 검증한다. 구조 누락 시 확인된 상품과 자체 문구로 보완하고 `format_repair`를 기록한다. 원래 글의 금지 표현과 주소 검증을 먼저 적용한다.
- 현재 라이브러리는 2026-10-07 브라우저로 찾고 확인한 자료다. 매 생성마다 인터넷을 새로 검색하는 기능은 아니다. 새 조사 시 기록을 갱신하고 반응이 적은 후보는 제외한다. 오래된 인기 검색 사례는 최근 유행으로 설명하지 않는다.
- 반응 수는 포맷의 성공 원인이나 구매 전환을 입증하지 않는다. 신규 포맷 적용 전후 노출·답글·사이트 유입·가입/결제를 각각 측정해 판단한다.
- 하루 10~20개, 계정 첫 주의 알고리즘, 외부 링크의 노출 저하 등 다른 운영자의 경험담은 검증된 규칙으로 구현하지 않는다.
- Instagram 제작 방식, 기존 예약과 예산, 게시 중복 방지·영수증 확인 절차는 기존대로 유지한다. 이미 제작된 작업은 소급 재작성하지 않으며 다음 새 기획부터 적용한다.

검증: `python scripts/test_promotion.py`, 프런트 `python tools/ship.py --check`, `python scripts/verify_threads_writing.py`.
텍스트 미리보기: `python scripts/verify_threads_writing.py --plan`. 공개 상품/포맷/기본 지시만 모델에 전송하며 관리자 설정·참고 이미지·작업 이력은 읽거나 전송하지 않는다. SNS 발행 없음.
