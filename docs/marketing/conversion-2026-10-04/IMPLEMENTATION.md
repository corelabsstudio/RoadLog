# 로드로그 가입 흐름 개선 · 2026-10-04

온해님이 10-03 분석 후 제안한 개선을 순차 적용·배포하도록 승인했다.

## 변경

- 첫 화면은 무료 오늘 운세 시작과 고민별 대표 경로 3개(속마음, 재회, 연락 시기)다. 가입 없이 입력을 시작한다.
- 가입 선물은 일반 사주 한 편의 전체 열람 이용권 + 등불 300개로 설명한다. 서버 `lamps.use_ticket`와 상품 정본을 확인했으며 프리미엄·결제 전용 상품 제외를 명시한다. 회원에게 가입 혜택 영역을 숨긴다.
- 기존 프리미엄·저주·꿈·관상·전당·전체 상품은 ‘다른 사주와 꿈·관상도 둘러보기’에서 열 수 있다. 원래 기능·상품·결제 조건을 유지한다.
- 일반 사주 입력은 5 → 3, 두 사람 사주는 10 → 5단계. 성별은 생년월일과 함께, 이름과 태어난 곳은 선택 항목으로 접어 넣는다. 계산에 필요한 생년월일·양음력·성별·시각·지역 입력과 확인/수정 경로를 유지한다. 본관이 있는 수호신은 추가 단계가 있다. 모바일 다음 버튼은 하단 메뉴 위에 붙여 가려지지 않게 한다.
- 상품 화면에 입력 바로가기 추가, 큰 장식 이미지가 입력을 밀어내지 않도록 조정.
- 소셜 인증의 취소·만료·예상되는 인증/통신 오류는 가입창으로 돌아가 재시도/이메일 대안을 안내한다. 인증 성공 동작은 유지한다. 꿈·반려동물·관상에서 소셜 로그인한 뒤 해당 화면으로 돌아온다. 사진이나 꿈 내용은 신규 분석 이벤트에 담지 않는다.
- 메인 비회원 진입, 네 대표 선택, 입력 시작/확인, 가입 안내, 이메일 제출/오류, 소셜 시작/오류, 기능별 진입/완료를 추가 집계한다. 신규 가입 성공은 기존 서버 가입 경로가 기록한다.
- 운영 화면에 새 이벤트와 ‘같은 날 메인을 연 비회원 중 가입’ 교집합을 추가한다. 기존 퍼널의 서로 다른 집계 대상 사이 ‘이전 항목 대비 %’를 제거한다. 새 집계는 10-04부터이며 과거 값을 채워 넣지 않는다.
- 사건은 기존 일별 IP+UA 해시와 중복 제거·운영자/봇 제외를 따른다. 개인정보나 인증 오류 원문을 분석 기록으로 보내지 않는다. 소셜 앱 이동/IP 변경·다음 날 가입은 메인 교집합에 연결되지 않을 수 있다. 순차 세션 퍼널이 아니다.
- Windows 배포 빌드는 npx.cmd 대신 정식 프로젝트 Vite를 Node로 실행한다. 전체 빌드가 기존 공개 SNS 이미지 링크를 지우지 않도록 `assets/social/`을 보존한다. 서비스워커는 기존부터 캐시를 저장하지 않으므로 캐시 버전 변경은 필요 없다.
