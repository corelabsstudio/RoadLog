## 2. 발견된 버그/이슈 목록 (우선순위순)

### [긴급/상]

#### 1) 최신 코드(업무 요약·export 포함) 미배포
- **위치:** 전 사이트 (`/build.json`, `/`, `/app.js`, `/api/logs/summary*`)
- **현상:**  
  - `build.json` = `20260727-vat-excl` 고정  
  - HTML에 `view-reports`, `업무 요약`, `PDF 저장` 등 없음  
  - `GET /api/logs/summary`, `/api/logs/summary/export` → **404 Not Found**  
  - `app.js`에 `loadReportsSummary` / `downloadReportFile` 없음  
- **재현:**  
  1. https://roadlog.co.kr/build.json 접속  
  2. https://roadlog.co.kr/api/logs/summary?period=month (로그인 토큰 포함) → 404  
- **영향:** 주간/월간 대시보드·PDF/Excel/이미지 다운로드 QA 자체가 불가  
- **조치:** Railway GitHub 연동/빌드 로그 확인. `main@86ccd02+` 강제 빌드 배포. 배포 후 build 문자열이 `20260727-reports-export` 등으로 바뀌는지 확인.

#### 2) (배포 후 재확인 필요) Free 한도 “누적 lifetime” 메타 미노출
- **위치:** `GET /api/meta`, `GET /api/me`
- **현상:** `free_limit=15` 이지만 `free_limit_period` 필드가 `None` (lifetime 커밋 미배포 가능)
- **재현:** `/api/meta` 응답에 `free_limit_period` 키 없음  
- **영향:** 프론트가 “이번 달” 문구를 쓸 수 있음(구 카피). 실제 차감 로직은 배포 코드에 따름  
- **조치:** free-lifetime 커밋 포함 배포 후 재검수

### [중]

#### 3) 일지 Excel 내보내기 format 키 혼선 (`xlsx` vs `excel`)
- **위치:** `POST /api/export`
- **현상:** `format: "xlsx"` → **400**  
  `"format은 excel | pdf | docx 중 하나여야 합니다."`  
  `format: "excel"` → **200** (정상 xlsx 바이너리)
- **재현:**  
  1. 로그인 후 일지 생성  
  2. `POST /api/export` body `{log, format:"xlsx"}` → 400  
  3. `format:"excel"` → 성공  
- **영향:** 프론트가 `excel`을 보내면 문제 없음. 외부 클라이언트/`xlsx` 호출 시 실패  
- **조치:** 서버에서 `xlsx`/`xls` alias 허용 또는 에러 메시지에 alias 안내. (현재 UI는 `excel` 사용 추정)

#### 4) 빈 폼 AI 생성 시 HTTP 200 + success:false 패턴
- **위치:** `POST /api/generate` (필수값 없이 호출)
- **현상:** 상태코드 200, body `success:false`, errors에 오전/오후 방문지 등 메시지  
- **재현:** 로그인 후 form 빈 객체로 generate  
- **영향:** 치명적 버그는 아니나, REST적으로 400이 더 명확. 프론트가 errors를 잘 띄우는지 브라우저 확인 필요  
- **조치:** (개선) 검증 실패 시 422/400 권장

#### 5) 반응형·실기기 UI 미검증 (환경 한계)
- **위치:** 전체 페이지
- **현상:** 375 / 768 / 1920 실브라우저 레이아웃 깨짐 여부는 이번 스위트에서 **미실행**  
- **조치:** Chrome 디바이스 모드로 수동 1회 스윕 권장

## 3. 통과한 핵심 시나리오 (실측)

- `/`, health, meta, robots, sitemap, legal md, app.js, styles, manifest → **200**
- CTA/요금제/pro-claim 앵커 HTML 존재
- 인덱스 참조 정적 자산 깨짐 없음

### Phase 2 — 인증
- 잘못된 이메일 가입 → 400  
- 정상 가입·로그인 → 200 + 토큰  
- 비로그인 me/logs/generate → 401  
- `/api/me` 세션 유지 → 200  

### Phase 3 — 일지
- 운행 AI 생성 (OpenAI) ~6.4s → 성공  
- 외근 AI 생성 (OpenAI) ~2.9s, visits=2 → 성공  
- 1200자 긴 텍스트 생성 → 200 (크래시 없음)  
- 일지 저장·목록 → 성공  
- PDF / DOCX 다운로드 → 성공  
- Excel → **`excel` 키로 성공**, `xlsx` 키는 400  

### Phase 4 — 요금/결제
- demo upgrade → 403 (결제 없이 plan 변경 차단)  
- claim 빈 주문번호 → 400  
- claim 정상 → 200  
- 생성 후 usage 증가 (예: 3/15, remain 12)  
- 결제 URL: 신규 스마트스토어 상품 ID 반영  

### Phase 5 — 헬스
